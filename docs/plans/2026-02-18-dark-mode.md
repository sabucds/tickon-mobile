# Plan: Dark mode support

## Goal
Make the design system fully brightness-aware using a `ThemeExtension` for custom
semantic colors, so atoms respond to light/dark automatically without any per-widget
`if (isDark)` logic.

## Strategy
- `AppColors` stays as the raw palette (no changes).
- NEW `AppColorsTheme` (ThemeExtension) maps semantic names → palette colors per brightness.
- `AppTypography` drops hardcoded `color` — text color comes from `colorScheme.onSurface` via Material.
- Atoms read `context.appColors.*` instead of `AppColors.*` for semantic slots.
- `AppTheme.dark` added; both themes register the extension.
- `MaterialApp` gets `darkTheme + ThemeMode.system`.

## Files to create
- `lib/core/ui/tokens/app_colors_theme.dart` — ThemeExtension + BuildContext helper

## Files to modify
- `lib/core/ui/tokens/app_typography.dart` — remove `color` from all const styles
- `lib/app/theme/app_theme.dart` — add `dark`, register extension in both themes
- `lib/core/ui/atoms/app_button.dart` — use `context.appColors` for secondary/disabled slots
- `lib/core/ui/atoms/app_text_field.dart` — use `context.appColors`
- `lib/main.dart` — `darkTheme: AppTheme.dark, themeMode: ThemeMode.system`
- `test/core/ui/atoms/app_button_test.dart` — add `AppTheme.light` to wrapper

## Rollback
Revert all modified files; delete `app_colors_theme.dart`.
